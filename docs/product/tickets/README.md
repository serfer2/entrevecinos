# Convención de organización de tickets

- Tickets ligados a una historia de usuario viven en `HU-xxx-<nombre-de-la-historia>/`, donde `xxx` es el número de la HU en `docs/product/user-stories.md` (p. ej. `HU-07-publicar-un-anuncio/`).
- Tickets técnicos/transversales que no pertenecen a una sola HU (infraestructura, herramientas de desarrollo, etc.) viven en `00-infra/`.
